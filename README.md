# 📊 Swiggy Sales Dashboard | Microsoft Excel

An interactive **Sales Dashboard** built in **Microsoft Excel** to analyze Swiggy sales data and generate meaningful business insights using Pivot Tables, Charts, KPI Cards, and Slicers.

---

## 📌 Project Overview

This project demonstrates how Excel can be used as a powerful Business Intelligence tool to analyze sales performance and create interactive dashboards.

The dashboard enables users to monitor sales trends, customer ratings, order performance, and regional sales through easy-to-use filters and visualizations.

---

## 🎯 Objectives

- Analyze overall sales performance
- Track monthly, weekly, and daily sales trends
- Identify top-performing cities
- Compare sales across food categories
- Visualize state-wise sales
- Build an interactive dashboard for business reporting
